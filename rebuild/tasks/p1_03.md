### TASK-P1-03: On-Disk Content Verification
Goal: verify a file on disk matches expected content, or that search/replace edits were fully applied.

File: TriAPI/rebuild/scripts/verify.py (append; `re` and `subprocess` already imported at top — add `import difflib` and `from pathlib import Path` if needed)

Signature:
```python
def verify_file_content(
    file_path: str,
    expected_content: str | None = None,
    search_replace_blocks: list[tuple[str, str]] | None = None,
) -> dict:
```

Behavior:
- Read file_path as UTF-8. If it doesn't exist: return passed=False, file_exists=False, diff="", violations=["File not found: {file_path}"].
- If expected_content is given: compare actual content to expected_content exactly. If different, add a unified diff (difflib.unified_diff, lineterm="") joined with "\n" to "diff", and violations.append("Content mismatch").
- If search_replace_blocks is given: for each (search_text, replace_text) pair — if search_text is still present in the actual content, violations.append(f"Search block still present: {search_text!r}"); if replace_text is NOT present in the actual content, violations.append(f"Replace block missing: {replace_text!r}").
- "passed" is True only if file_exists is True and violations is empty.
- If neither expected_content nor search_replace_blocks is given, treat as no checks requested: passed=True (file_exists still checked), violations=[].

Return dict with exactly: "passed" (bool), "file_exists" (bool), "diff" (str), "violations" (list[str]).

Scope:
- In scope: reading the file, difflib comparison, literal substring checks.
- Out of scope: no writing/modifying files, no git commands, no subprocess/test execution.
