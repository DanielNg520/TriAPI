### TASK-P1-04: Scope Boundary Diff Validator
Goal: diff before/after file content, flag changes outside an allowed function or line range.

File: TriAPI/rebuild/scripts/verify.py (append; `ast` and `difflib` may be needed — `difflib` already imported)

Signature:
```python
def verify_scope_boundaries(
    before_content: str,
    after_content: str,
    allowed_function_name: str | None = None,
    allowed_line_range: tuple[int, int] | None = None,
) -> dict:
```

Behavior:
- Determine allowed_range (1-indexed inclusive (start, end)):
  - If allowed_function_name given: parse `before_content` with `ast.parse`, find a top-level or nested FunctionDef/AsyncFunctionDef named allowed_function_name, use (node.lineno, node.end_lineno) as allowed_range. If not found, or before_content isn't valid Python, allowed_range = None.
  - Else if allowed_line_range given: use it directly.
  - Else: allowed_range = None (nothing restricted — every changed line is a violation is wrong in this case; instead treat as unrestricted: passed=True, no violations, but still compute modified_lines and diff).
- Compute modified_lines: 1-indexed line numbers in after_content that differ from before_content (inserted or changed), via difflib line comparison (e.g. difflib.SequenceMatcher or unified_diff parsing — your choice, but must be correct for simple insert/delete/replace cases).
- If allowed_range is not None: any modified line number outside [allowed_range[0], allowed_range[1]] is a violation: violations.append(f"Line {n} modified outside allowed span {allowed_range}").
- If before_content == after_content: modified_lines = [], violations = [], passed = True (nothing changed, trivially in scope).
- "passed": True iff violations is empty.
- "diff": unified diff string (difflib.unified_diff, lineterm="", joined with "\n") between before_content and after_content.

Return dict with exactly: "passed" (bool), "allowed_range" (tuple[int,int] | None), "modified_lines" (list[int]), "violations" (list[str]), "diff" (str).

Scope:
- In scope: ast parsing for function boundaries, difflib for line diffing.
- Out of scope: no regex heuristics on task descriptions, no filesystem/subprocess access.
